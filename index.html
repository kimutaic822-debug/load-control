About Load Control

This app is a smartphone interface for remotely switching AC loads (like a lamp or fan) and monitoring their voltage, current and power draw. It's built for use with an ESP32 microcontroller and relay modules.

Right now every reading is simulated so the interface and control flow can be tested ahead of the hardware build. Once the ESP32 is wired up, the app's simulated readings get replaced with real HTTP calls to the device's IP address, which you can set under Settings.
